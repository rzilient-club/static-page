What the assistant can do

_twelve_tools_reviewed_by_hand

Every tool is written and reviewed by rzilient, never generated from the API spec. Reads are broad; writes are deliberately narrow.

read rzilient_list_devices

List devices

Filter by status, category, assignee, online state, encryption or tag. Paginated.

read rzilient_search_devices

Search devices by meaning

"Old Apple laptops with small disks in sales." Semantic search over the fleet, no exact filters needed.

read rzilient_get_device

Get device

One device by id or serial number, with hardware, OS, MDM and security details.

read rzilient_list_employees

List employees

Search by name or email, filter by role, manager or active state.

read rzilient_get_employee

Get employee

One person by id or email, including the devices assigned to them.

read rzilient_list_orders

List orders

Filter by status, type, employee or date range.

read rzilient_get_order

Get order

Line items, addresses and tracking events for one order.

read rzilient_recent_activity

Recent activity

The activity feed, newest first. Filter by event, unread or since a date.

write rzilient_update_device

Update device

Replace tags, set a description or assign the device to an employee. Same rules as the dashboard.

write rzilient_onboard_employee

Onboard employee

Create an account with role, manager and start date. Optionally send the invitation.

write rzilient_update_employee

Update employee

Name, phone, role, manager, onboarding and offboarding dates.

confirm rzilient_offboard_employee

Offboard employee

Deactivate an account. Refused unless the assistant confirms it with you first.

Built for trust

_your_data_stays_yours

The assistant sees exactly what the person who connected it can see, and nothing else.

1 Company per connection. The tenant comes from the token, on every single request.
4 Write actions, and only the safe ones: tags, descriptions, assignments and employee lifecycle.
0 Tool arguments logged. Names, emails and serial numbers never reach the logs.
1 click To revoke access: delete the token in Settings, and every assistant using it stops instantly.
  • Enabled per company. AI assistant connections are off until rzilient activates them for you.
  • Same permissions as the dashboard. Device assignment goes through the same transitions a manager would use.
  • Offboarding always asks first. The tool refuses to run unless the assistant confirmed it with you.
  • Rate limited. 120 requests per minute per token, so a runaway agent cannot hammer your data.
  • Standards based. Streamable HTTP transport, OAuth 2.1 with PKCE, RFC 9728 and RFC 8414 discovery documents.
  • Visible in the dashboard. Writes made by an assistant show up as notifications for the manager who connected it.

Getting started

_how_to_connect

Managers connect their own assistant in a minute. Partners register an application once and let their customers sign in.

For Clients

  • Step 1: Open Settings → AI assistants in the rzilient dashboard
  • Step 2: Generate an API token. It is shown once, so copy it
  • Step 3: Paste the generated command or JSON into your assistant
  • Done: Ask a question. Type /mcp in Claude Code to see the tools

For Partners

  • Step 1: Register an OAuth application from Settings → OAuth Applications
  • Step 2: rzilient reviews it and delivers the client secret once
  • Step 3: Your customers add the connector and sign in with rzilient
  • Done: Each token is bound to the company that consented
